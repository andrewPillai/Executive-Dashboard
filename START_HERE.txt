FASTEST WAY TO RUN (macOS/Linux)
Prerequisite: Python 3.12, internet access for dependency installation.
From the extracted bundle:
  cd application
  python3 -m venv .venv
  .venv/bin/python -m pip install -r python-requirements.lock
  .venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
Open http://127.0.0.1:8000/ . The compiled frontend is already included.
If another process uses port 8000, choose another port in that command.
After setup, you can also start with: sh run-demo.sh

WINDOWS (PowerShell)
  cd application
  py -3.12 -m venv .venv
  .\.venv\Scripts\python.exe -m pip install -r python-requirements.lock
  .\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
Windows has not been exercised in this session; these are standard equivalent commands.

REBUILD THE FRONTEND
Prerequisites: Node.js 24 and pnpm 11.19.0. If pnpm is not installed, install the
pinned version using your normal Node package-manager setup, for example:
  npm install --global pnpm@11.19.0
Then from application/:
  cd frontend
  pnpm install --frozen-lockfile
  pnpm build
  cd ..
The approved dependency build policy is in pnpm-workspace.yaml (esbuild only).
The original machine's bundled pnpm runtime required:
  pnpm --config.verify-deps-before-run=false build
Use that only for an already-installed dependency tree. Do not skip installation.
Production FastAPI serves frontend/dist on the same origin. During frontend
work, pnpm dev proxies /api to the backend on port 8000.

VALIDATE
From application/ using its Python environment:
  .venv/bin/python -m pytest backend -q
  .venv/bin/python tools/verify_delivery.py
From bundle root with any Python 3:
  python3 verify_bundle.py
An isolated browser-review workflow is available with:
  .venv/bin/python tools/serve_review.py
It uses port 8001 and temporary workflow state; the business fixture is shared read-only.
